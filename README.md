# LexO-server site

Static website for the LexO-server Suite.

## Local preview

Because the site is static, it can be previewed with any local HTTP server. For example:

```bash
python3 -m http.server 8000
```

Then open `http://localhost:8000` in a browser.

## Deployment

`index.html` remains in the repository root, so the project can be deployed directly with GitHub Pages or another static hosting service.
