Welcome to LexO-server Suite

A RESTful service infrastructure designed for the collaborative management of linguistic resources modeled according to the Linked Data paradigm.

Enables the creation, editing, and deletion of complex dictionaries and lexicons, modeled as interoperable Knowledge Graphs.

🔗 Linked Data

Implementation of international W3C de facto standards such as OntoLex-Lemon, Lexicog, SKOS, and LexInfo for data interoperability.

🛠 RESTful Management

Robust API services for dynamic manipulation of lexical resources modeled as RDF graphs.

🔓 Free & Open Source

LexO-server is freely available as open-source software, enabling transparent reuse, extension, and deployment without vendor lock-in.

Data Model

LexO-server is built on a modular framework. While OntoLex-Lemon and Lexicog constitute the structural Core Models of the system, they are designed to be extended by Complementary Modules.

Core Model

OntoLex-Lemon fully implemented

The foundational standard for publishing lexicons on the Semantic Web, enabling the seamless integration between lexical data and ontologies. Module Details

Reference Paper:McCrae, J. P., Bosque-Gil, J., Gracia, J., Buitelaar, P., Cimiano, P. (2017) The Ontolex-Lemon model: development and applications. In Proceedings of eLex 2017 conference (pp. 19–21).
Core Model

Lexicog fully implemented

Designed to reflect traditional dictionary structures and the formal organization of lexicographic entries. Module Details

Reference Paper:Bosque-Gil, J., Gracia, J., Montiel-Ponsoda, E. (2017) Towards a Module for Lexicography in OntoLex. In Proceedings of the 1st Workshop on the OntoLex Model (pp. 74–84).
Complementary module

Decomposition fully implemented

Modeling the internal structure of compound words and multi-word expressions. Module Details

Reference Paper:Benzoni, E., Pellegrini, M., Dedè, F., Passarotti, M. (2024) Representing Compounding with OntoLex. An Evaluation of Vocabularies for Word Formation Resources. In Proceedings of LREC-COLING (pp. 13958–13969).
Complementary module

Variation & Translation partially implemented

Managing semantic relations between variants and cross-lingual translations. Module Details

Reference Paper:Bosque-Gil, J., Gracia, J., Aguado-de-Cea, G., Montiel-Ponsoda, E. (2015) Applying the OntoLex model to a multilingual terminological resource. In Proceedings of the European Semantic Web Conference (pp. 283–294).
Complementary module

Syntax & Semantics not implemented

The interface between lexical items and their syntactic behavior and semantic argument structure. Module Details

Complementary module

FrAC not implemented

Integrating frequencies, attestations, and data from external corpora. Module Details

Reference Paper:Chiarcos, C., Apostol, E. S., Kabashi, B., Truică, C. O. (2022) Modelling frequency, attestation, and corpus-based information with OntoLex-FrAC. In Proceedings of COLING (pp. 4018–4027).
Complementary module

LemonEty partially implemented

Representing the history and evolutionary genealogy of lexical units. Module Details

Reference Paper:Khan, A. F. (2018) Towards the Representation of Etymological Data on the Semantic Web. Information 9(12), 304.
Complementary module

LexFom fully implemented

Representing lexical functions in the Meaning–Text Theory framework and formally modelling semantic and combinatorial relations between lexical units. Module Details

Reference Paper:Fonseca, A., Sadat, F., Lareau, F. (2016) Lexfom: a lexical functions ontology model. In Proceedings of CogALex (pp. 145–155).

Applications of LexO-server in Research Projects

VocaBO
The first native digital vocabulary devoted to the language of Giovanni Boccaccio, starting from the Decameron. It combines scientific lexicography and Digital Humanities methods to make words, meanings, semantic fields, and textual occurrences openly accessible and searchable.
OWNW
OWNW – Old Words for a New World investigates how Christian terminology was translated and adapted in the earliest Baltic catechisms, combining historical linguistics, religious studies, computational lexicography, and knowledge representation.
ItAnt
ItAnt investigates the cultures of ancient Italy through linguistic and epigraphic documentation, combining historical linguistics, philology, epigraphy, and computational methods according to FAIR and Linked Open Data principles.
DiTMAO
DiTMAO is devoted to a dictionary of Old Occitan medico-botanical terminology and uses LexO-server services to model terms, variants, translations, conceptual references, and links to domain knowledge.
